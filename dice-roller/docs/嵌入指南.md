# DiceRoller 嵌入指南

给要把物理骰子接到 **另一个 Godot 4 C# 项目** 的程序员或 agent。领域用语见 [CONTEXT.md](../CONTEXT.md) 与 [adr/0001-face-slot-and-content.md](./adr/0001-face-slot-and-content.md)。移植背景见 [项目文档.md](./项目文档.md)。

本仓库里已经有一份最小宿主：[`scenes/test_headless_table.tscn`](../scenes/test_headless_table.tscn) + [`scripts/HeadlessTableApp.cs`](../scripts/HeadlessTableApp.cs)。先对照它，再抄到别的工程。

**不要**实例化 [`scenes/main.tscn`](../scenes/main.tscn) 或 [`addons/dice_roller/Ui/DiceHud.tscn`](../addons/dice_roller/Ui/DiceHud.tscn)，除非宿主也要这套演示 UI。

---

## 1. 先记住的三件事

1. **朝上结果是 `RollOutcome`，不是 `int`。** 几何槽位是 `FaceSlotId`，含义是 `FaceContent.Id`（及可选 `NumericValue` / `Payload`）。禁止把 `GetRolledSide() -> int` 当公共 API。
2. **入口是 `IDiceTable`。** 场景根 [`DiceTable`](../addons/dice_roller/Physics/DiceTable.cs) 与 [`DiceManager`](../addons/dice_roller/Physics/DiceManager.cs) 都实现它。宿主代码面向接口，不要去点 HUD 按钮。
3. **许可是 GPL-3.0。** 拷贝网格、材质、图标或派生脚本后，发行物通常也必须 GPL。闭源宿主需自绘资源并独立实现逻辑，或另获授权。详见项目文档 §3.1。

引擎：Godot **4.7** + C# / .NET 8，物理建议 **Jolt**（与本仓库一致）。

---

## 2. 拷贝清单

骰子网格、材质与墙体已在插件内（`addons/dice_roller/assets/`）。宿主 **只拷** `addons/dice_roller/`，不要改这些 `res://addons/dice_roller/assets/...` 路径。

| 拷贝 | 用途 |
|------|------|
| `addons/dice_roller/` | Core / Physics / Session / Settings / Presentation / Ui / **assets**（`dice/` + `world/wall.tscn`） |

可选：

| 拷贝 | 何时需要 |
|------|----------|
| `Interface/Icons/` | 只要演示 `DiceHud`（图标仍在工程根，不在插件内） |
| `scenes/test_headless_table.tscn` + `scripts/HeadlessTableApp.cs` | 当参考，不必进发行包 |

不要拷：

- `scenes/main.tscn`、`scripts/DiceTableApp.cs`（演示应用）
- `docs/`、`tests/`（除非你要对照）
- 原 Godot 3 工程 `d:\GitHub\diceRoller`

尚无 `plugin.cfg`，不是 EditorPlugin。用运行时类库文件夹 + Autoload。

## 3. 宿主 `project.godot` 必做

### 3.1 Autoload（名称必须一致）

`DiceManager` / `DieBody` 用节点路径 `/root/DiceSession`、`/root/SettingsStore`：

```
[autoload]

DiceSession="*res://addons/dice_roller/Session/DiceSession.cs"
SettingsStore="*res://addons/dice_roller/Settings/SettingsStore.cs"
```

不要改这两个 Autoload **名称**。可以改键位，不要改这两个脚本的 GlobalClass 依赖方式。

### 3.2 物理层

骰子 `collision_layer = 2`、场地 `layer = 1`。宿主应对齐：

```
[layer_names]

3d_physics/layer_1="Box"
3d_physics/layer_2="Dice"
```

并启用 Jolt（推荐）：

```
[physics]

3d/physics_engine="Jolt Physics"
3d/default_gravity=10.0
```

世界重力 10 与骰子 `gravity_scale`（设置键 `gravity`，默认 **4**）是两套值，不要混成一个滑条。

### 3.3 C#

宿主 csproj 用 `Godot.NET.Sdk`，能编译到 `addons/dice_roller/**/*.cs`（Godot C# 工程默认包含）。命名空间：

| 命名空间 | 宿主该不该依赖 |
|----------|----------------|
| `DiceRoller.Core` | 要：`RollOutcome`、`FaceLayout`、`FaceContent`、`HullKind`、`NumericScore`、`SessionStats` |
| `DiceRoller.Physics` | 要：`IDiceTable`、`DiceTable`、`DieBody` |
| `DiceRoller.Session` | 通常只要 Autoload；读 `Outcomes` / `CountByContentId` |
| `DiceRoller.Settings` | 改颜色/重力时 |
| `DiceRoller.Ui` | 仅当挂 `DiceHud` |
| `DiceRoller.Presentation` | 自定义 Presenter 时 |

禁止新的 `$"/root/main"`。用导出节点、组、或 `GetNode` 相对路径。

## 5. 代码怎么写

### 5.1 生成标准数字骰

```csharp
using DiceRoller.Core;
using DiceRoller.Physics;

IDiceTable table = GetNode<DiceTable>("DiceTable");
DieBody die = table.SpawnStandard("d20"); // 或 SpawnStandard(HullKind.D20)
```

合法壳体字符串（大小写不敏感）：`d4` `d6` `d8` `d10` `d12` `d20`。解析见 `HullKinds.Parse` / `TryParse`。未知字符串会抛 `ArgumentException`。

自定义面布局（生成时）：

```csharp
var def = new DieDefinition
{
    Hull = HullKind.D6,
    Layout = FaceLayouts.StandardNumeric(HullKind.D6),
};
DieBody die = table.Spawn(def);
die.Layout.Replace(new FaceSlotId(6), new FaceContent
{
    Id = "fireball",
    Label = "Fireball",
    TextureKey = "res://game/icons/fireball.png", // ImageFacePresenter 用；Core 不当 Texture2D
    Payload = yourCard,            // 宿主类型，Core 是 object?
});
```

`FaceSlotId.None`（值为 0）**不是** Layout 的键，`Replace` / 索引都会抛。

只改 **含义**、不换外观时：`Replace` 的 `FaceContent` 可以不设 `TextureKey`，也不必安装 `ImageFacePresenter`。朝上读取立刻用新的 `Id` / `Payload`。

### 5.1.1 自定义面（贴图）

默认骰子网格是「本体 + 烘焙数字」两套 surface，UV **没有**按 `FaceSlotId` 切开。换外观用 [`ImageFacePresenter`](../addons/dice_roller/Presentation/ImageFacePresenter.cs)：按槽叠 **Decal**，采样方向与朝上检测相同（`DieFaceMap`），**不要**改采样向量来「对齐贴图」。

`FaceContent.TextureKey` 必须是 Godot 资源路径（`res://...`）。Core 把它当字符串，不当 `Texture2D`。

**每颗骰子一个 Presenter 实例**（Decal 挂在该骰的 `Mesh` 上）。两种接法：

```csharp
using DiceRoller.Presentation;

// 这一颗
var die = table.Spawn(def, new ImageFacePresenter());

// 这一桌之后生成的都换面（含 HUD 的 SpawnStandard）
GetNode<DiceManager>("DiceTable/DiceManager").CreatePresenter =
    () => new ImageFacePresenter();
```

生成时带齐 Layout，或之后 `Replace`：已安装的 Presenter 会随 `Layout.Changed` 再 `Apply`。

```csharp
var layout = FaceLayouts.StandardNumeric(HullKind.D6);
layout.Replace(new FaceSlotId(6), new FaceContent
{
    Id = "fireball",
    Label = "Fireball",
    TextureKey = "res://game/icons/fireball.png",
    Payload = yourCard,
});
var die = table.Spawn(
    new DieDefinition { Hull = HullKind.D6, Layout = layout },
    new ImageFacePresenter());
```

本仓库演示贴图：`DiceAssets.ExampleFace`（`res://addons/dice_roller/assets/faces/example.png`）。对照：`test_headless_table.tscn` 在 slot 6 贴了它；主场景 F2 同样。

要点：

- 未设 `TextureKey` 的槽保持烘焙数字（`HideBakedNumerals` 默认 `false`）。
- `new ImageFacePresenter { HideBakedNumerals = true }` 会藏数字 surface：没贴图的面是空白，应给 **所有槽** 都设 `TextureKey`。
- `Payload` 只给宿主规则用，Presenter 不读。
- 自有网格若已按面拆 UV，可以实现自己的 `IFacePresenter`（`Bind` / `Apply` / `Unbind`），不必用 Decal。
- 默认工厂仍是 `BakedNumeralPresenter`：不改 `CreatePresenter`、不传第二参 `Spawn`，外观与烘焙数字骰相同。

### 5.2 读结果（主路径）

骰子约每秒 `Poll` 一次，停稳后也会通过 `DieBody.Rolled` → `IDiceTable.Rolled` / `DiceSession.Recorded`。

```csharp
table.Rolled += OnRolled;

void OnRolled(RollOutcome outcome)
{
    if (!outcome.IsValid)
        return; // Invalid：斜靠/叠放，Content 为 FaceContent.None，不要当成点数 0

    string id = outcome.Content.Id;       // RPG：按 Id 结算
    int? pips = outcome.Content.NumericValue; // 传统骰才有
    FaceSlotId slot = outcome.Slot;       // 几何槽，不是“几点”
}
```

立刻采样当前姿态（不掷）：

```csharp
RollOutcome now = die.PollNow();
```

`Layout.Replace` 后同一刚体、同一姿态再 `PollNow()`，应读到新的 `Content.Id`，不必销毁实例。

### 5.3 合计与分面（可选）

```csharp
var session = GetNode<DiceSession>("/root/DiceSession");
int sum = NumericScore.Sum(session.Outcomes); // 跳过 Invalid 与无 NumericValue（如 sword）
int swords = session.CountByContentId("sword");
var byHull = SessionStats.ByHull(session.Outcomes); // 按壳体；Invalid 计数单独有
```

`NumericScore.Sum` **不是** `IDiceTable` 的成员，也不是唯一结果。卡牌/RPG 可以完全不用它。

### 5.4 场上操作

```csharp
table.RollAll();
table.RollInvalid();
table.LockValid();     // 再调用一次解锁
table.Clear();         // 全清
table.Clear(HullKind.D6);
int n = table.Count;   // 场上未销毁的 DieBody 数量
```

销毁走 `DieBody.Die()`（Manager 已接好 `Forget`）。不要自己 `QueueFree` 却不通知 Session，否则会留幽灵统计。

### 5.5 设置

`SettingsStore.Set` **立刻写** `user://settings.json`（颜色为 HTML `#rrggbb`）。

常用键：`gravity`（float，骰子 GravityScale）、`body_color` / `number_color` / `border_color`、`allow_locked_move`（bool）。改颜色后演示应用会调 `DiceTheme.Apply`；宿主若不用演示主题，需自己听 `Changed`。

没有设置窗口不等于没有存储。关窗保存是 7b；现在 `Set` 即落盘。

## 6. 输入（抓取 vs 演示 HUD）

`DiceTable` 里的抓取脚本使用 Input Map 动作名（键位可改，**动作名建议保留**）：

| 动作 | 默认（本仓库） | 谁用 |
|------|----------------|------|
| `up` / `down` | W / S | 拖着时抛出 / 右键等价锁定 |
| `left` / `right` | **D / A**（与原版一样对调） | 拖着时旋转 |
| `delete` | Backspace | 删除悬停骰 |

鼠标：左键拖、双击抛、右键锁。这些在 `DiceInteractionController`，不经过 HUD。

仅 `DiceHud` 才需要：`roll`、`roll_invalid_only`、`lock_dice`、`clear`、`add_die`、`number_shortcut`。最小宿主可以不注册它们，改由代码调 `IDiceTable`。

## 7. 禁止与易错

| 不要 | 要 |
|------|----|
| `int rolledSide` 当唯一结果 | `RollOutcome` + `Content.Id` |
| 把 Invalid 写成点数 0 | `IsValid == false`，显示 `?` |
| 实例化 `main.tscn` 当插件 | 实例化 `DiceTable.tscn` |
| `$"/root/main"` | 导出 `DiceTable` / 相对 `GetNode` |
| 改 `DieFaceMap` 采样向量来“规范化” | 采样点保持原版；换图走 `ImageFacePresenter` / 自写 Presenter |
| 把 `TextureKey` 写成逻辑名（如 `cards/fireball`） | 必须是 `res://` 贴图路径 |
| 解析 `4d6d1` | 指令语法未实现 |

`HullKind` 只表示壳体。`"d6"` 不是“这颗骰子是数字 1–6”的同义词；面上可以是剑、法术、卡牌。

## 8. 给 agent 的最短任务清单

1. 拷贝 `addons/dice_roller/` 到宿主（骰子场景在 `assets/dice/`，墙在 `assets/world/wall.tscn`）。
2. 按 §3 加 Autoload 与物理层。
3. 新建场景：相机 + 灯 + instance `DiceTable.tscn`。
4. 脚本：`GetNode<DiceTable>("DiceTable")` 赋给 `IDiceTable`。
5. `SpawnStandard("d6")`，订阅 `Rolled`，用 `Content.Id` 结算。
6. 需要改面含义：`die.Layout.Replace(slot, content)`，再 `PollNow()`。需要换贴图：§5.1.1，`Spawn(..., new ImageFacePresenter())` 且 `TextureKey` 为 `res://`。
7. 需要合计：`NumericScore.Sum(session.Outcomes)`。
8. 不要挂 `DiceHud`，除非产品就要那套左右栏。
9. 发行前核对 GPL。

验证：场上有刚体；停下后 `Rolled` 有 `IsValid` 或 Invalid；`Replace` 后同一颗骰 `PollNow()` 的 `Content.Id` 已变。本仓库可用 Godot 打开 `res://scenes/test_headless_table.tscn` 对照，控制台应出现 `headless: count=1 layout[6]=sword`。
